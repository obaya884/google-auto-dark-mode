# Auto Dark Mode for Gmail & Sheets

端末のダークモード設定に合わせて、Gmail と Google スプレッドシートを暗く表示する Chrome 拡張機能です。

## 特徴

- 端末がダークなら Gmail とスプレッドシートを暗くし、ライトなら元の表示に戻します。端末の設定が変わると、開いているタブにも再読み込みなしで反映します。
- ツールバーのアイコンから開くメニューで、手動でも切り替えられます。手動の切り替えは一時的なもので、端末の設定が次に変わると端末の設定に合わせ直します。
- Gmail とスプレッドシートのそれぞれで、この拡張を使うかどうかを選べます。
- スプレッドシートはセルの背景も含めて全体を暗くします。

Chrome の「デザイン」の設定でライトかダークを選んでいる場合は、端末の設定の代わりに Chrome の設定に従います。

## 制約

画面全体の色を反転させる方法で暗くしているため、次の制約があります。

- Gmail 自身のテーマをダークにしていると、反転で逆に明るくなります。Gmail のテーマは既定の明るいもので使ってください。
- スプレッドシートの色を付けたセル、グラフ、貼った画像は、元と違う色で見えます。
- Gmail のメール本文も反転します。配色のある HTML メールは色が変わって見えます。写真などの画像は元の色で見えます。
- サイトのスイッチを切っているか、手動でライトに切り替えているときは、端末がダークだとページを開いた直後に暗い表示が一瞬見えることがあります。
- 手動で切り替えたあと、Gmail もスプレッドシートもメニューも開いていないあいだに端末の設定が 2 回変わって元に戻ると、手動の切り替えが残ります。

## インストール方法（開発者モード）

1. このリポジトリをクローンまたはダウンロードします。
2. 依存関係をインストールします。
   ```bash
   npm install
   ```
3. プロジェクトをビルドします。
   ```bash
   npm run build
   ```
4. Chrome で `chrome://extensions` を開きます。
5. 右上の「デベロッパー モード」をオンにします。
6. 「パッケージ化されていない拡張機能を読み込む」をクリックし、プロジェクト内の `dist` フォルダを選択します。

## 開発用コマンド

- `npm run build`: プロジェクトをビルドし、`dist` ディレクトリに出力します。
- `npm run dev`: ファイルの変更を監視して自動でビルドします。
- `npm test`: テストを実行します。
- `npm run clean`: `dist` ディレクトリを削除します。
- `npm run zip`: ビルドして `dist` ディレクトリを zip で圧縮します。

## プロジェクト構成

```
.
├── src/
│   ├── state.ts        # 表示を決めるロジック（DOM と chrome の API に触れない）
│   ├── storage.ts      # chrome.storage.local の読み書き
│   ├── content.ts      # コンテンツスクリプト（<html> の属性を付け外しする）
│   ├── dark.css        # 反転のスタイル
│   └── popup.*         # ツールバーのメニュー
├── test/               # jest のテスト
├── _locales/           # 翻訳ファイル (i18n)
├── icons/              # 拡張機能アイコン
├── manifest.json       # 拡張機能の設定ファイル
├── webpack.config.js   # Webpack 設定
└── tsconfig.json       # TypeScript 設定
```

## 仕組み

端末の設定に従う表示は `dark.css` の `@media (prefers-color-scheme: dark)` だけで切り替えています。コンテンツスクリプトは手動の切り替えやサイトのスイッチで端末の設定と違う表示にするときだけ、`<html>` に `data-auto-dark` 属性を付けます。

手動の切り替えは切り替えた時点の端末の設定と一緒に保存しています。今の端末の設定がそれと違っていれば、手動の切り替えを無視して消します。
